# 搜尋最佳實踐

為了獲得最精確、最相關的搜尋結果，請參考以下建議。

## 1. 選擇合適的搜尋模式 (`mode`)

- **`keyword_transcript_only`**: 最適合精確關鍵字搜尋，範圍僅限於逐字稿內容。
- **`keyword_all_fields`**: 當您不確定關鍵字出現在哪個欄位時使用，範圍更廣。
- **`semantic_search`**: 當您想尋找概念或意義相近的內容，而不僅是字面匹配時使用。
- **`hybrid_search`**: 結合了關鍵字和語意搜尋的優點，是多數情境下的推薦選項。

## 2. 善用引號進行精確匹配

如果您想搜尋一個完整的詞組，請使用引號將其括起來。例如，`"數位身分證"` 會比 `數位身分證` 找到更精確的結果。

## 3. 結合多個篩選條件

盡可能提供多個篩選條件，例如 `speakers`、`committees` 和日期範圍，這能大幅縮小搜尋範圍，提高結果的相關性。

## 4. 從寬鬆到嚴格

如果您一開始找不到結果，可以先嘗試較寬鬆的條件（例如，只用 `query`），然後逐步加入更多篩選條件來收斂結果。

## 5. 調整摘要長度與上下文

- 如果您需要更完整的上下文，可以適度增加 `max_excerpt_length` 和 `max_context_sentences` 的值。
- 如果您只需要快速預覽，可以減少這些值以獲得更簡潔的結果。
