# IVOD 影片下載使用手冊

## 功能簡介

IVOD 影片下載功能讓您可以直接在瀏覽器中下載立法院 IVOD 影片，無需經過伺服器處理，保護您的隱私並節省伺服器資源。

## 如何使用

### 1. 尋找可下載的影片
- 瀏覽 IVOD 逐字稿列表
- 點擊任一筆記錄進入詳細頁面
- 如果該記錄包含影片連結，會看到「下載影片」按鈕

### 2. 開始下載
- 點擊「下載影片」按鈕
- 系統會自動解析影片來源並開始串流下載
- 下載過程中會顯示進度條和已下載大小

### 3. 下載完成
- 影片會自動儲存到您的下載資料夾
- 檔案名稱格式：`ivod-{編號}-{會議標題}.ts`
- 檔案為 TS 格式，可用 VLC 等播放器開啟

## 系統需求

### 瀏覽器支援
- **桌面瀏覽器**：Chrome 85+、Firefox 80+、Safari 14+、Edge 85+
- **行動瀏覽器**：支援現代行動瀏覽器
- **必要功能**：需支援 Fetch API 和 Blob 物件

### 硬體需求
- **記憶體**：建議至少 2GB 可用記憶體
- **儲存空間**：確保有足夠空間儲存下載的影片
- **網路連線**：穩定的網際網路連線

## 技術特色

### 串流式下載
- 採用分批下載技術，每批處理 5 個影片片段
- 大幅減少記憶體使用，記憶體效率比達 17:1
- 支援大型影片檔案（180MB 以上）

### 智慧解析
- 自動解析 M3U8 播放列表格式
- 處理巢狀播放列表結構
- 自動選擇最佳畫質進行下載

### 安全隱私
- 完全在您的瀏覽器中處理，不經過伺服器
- 下載過程不會在伺服器留下任何記錄
- 保護您的觀看隱私

## 檔案格式說明

### MP4 格式特點
- **格式名稱**：MPEG-4 Part 14（.mp4）
- **品質**：高品質影片格式，保持原始畫質
- **相容性**：最佳跨平台支援，所有裝置都可播放

### 推薦播放器
- **內建播放器**：Windows Media Player、QuickTime Player、VLC
- **網頁瀏覽器**：Chrome、Firefox、Safari 都可直接播放
- **行動裝置**：iPhone、Android 內建播放器完全支援
- **串流平台**：可直接上傳到 YouTube、Facebook 等平台

### 技術優勢
系統採用 **FFmpeg WebAssembly** 技術：
- **即時轉換**：下載過程中同步進行格式轉換
- **無需外部軟體**：完全在瀏覽器內完成，無需安裝額外程式
- **高效壓縮**：使用 `-c copy` 參數避免重新編碼，保持品質與速度
- **記憶體優化**：轉換完成後自動清理暫存檔案

## 常見問題

### Q：為什麼要轉換成 MP4 格式？
A：MP4 具有最佳的跨平台相容性，所有裝置和播放器都支援，也可以直接上傳到社群媒體平台。

### Q：轉換需要多長時間？
A：轉換時間取決於影片大小和設備效能。一般 3-5 分鐘的影片約需 30-60 秒轉換時間。系統會顯示即時進度。

### Q：下載中斷了怎麼辦？
A：目前系統不支援斷點續傳，如果下載中斷需要重新開始。建議在網路穩定時進行下載。

### Q：轉換失敗怎麼辦？
A：如果 MP4 轉換失敗，請檢查：1) 瀏覽器是否支援 WebAssembly；2) 記憶體是否充足；3) 網路連線是否穩定。建議使用桌面版 Chrome 或 Firefox。

### Q：可以同時下載多個影片嗎？
A：建議一次下載一個影片，避免瀏覽器記憶體壓力過大。

### Q：下載的影片可以分享嗎？
A：請遵守著作權法規定，下載的影片僅供個人學習研究使用。

### Q：手機可以下載嗎？
A：可以，但由於手機記憶體限制，建議只下載較小的影片檔案。

## 故障排除

### 下載失敗
- 檢查網路連線是否穩定
- 確認瀏覽器支援度
- 重新整理頁面後再試一次
- 清除瀏覽器快取

### 記憶體不足
- 關閉其他不必要的瀏覽器分頁
- 重新啟動瀏覽器
- 考慮使用桌面版瀏覽器而非行動版

### 播放問題
- 確認使用支援 TS 格式的播放器
- 檢查下載的檔案是否完整
- 嘗試用不同播放器開啟
